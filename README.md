# English Vocabulary Trainer

A production-quality vocabulary analysis + quiz web app for English learners.

## Features
- Enter an English word/term
- Choose target translation language
- Get: definition, translation, CEFR, part of speech, synonyms, antonyms, collocations, examples, usage notes, common mistakes
- Take an interactive quiz generated from the word
- Score + feedback, retry quiz, analyze another word (no refresh)

## Tech
- Client: React + TypeScript + Vite + Tailwind
- Server: Node + Express + TypeScript
- AI: Groq API (server-side proxy; keys never exposed to the client)
